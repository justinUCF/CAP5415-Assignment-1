# Canny Edge Detection PA-1

## Requirements
- Python 3
- pip install -r requirements.txt

## How to run
Run from the PA-1/ folder (not from inside code/), so the relative
image paths in canny.py resolve:

    python code/canny.py

## What you'll see
- One pipeline grid per image and an effect of sigma window comparing for that image.
- Press any key to advance to the next window.

## Output files
Images saved to code/figures/:
- <image>_pipeline.png (labeled grids)
- sigma_comparison.png (sigma comparison)
